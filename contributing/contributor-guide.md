# Contributor Guide

Thanks for contributing to Haven.

## How to contribute

1. Pick an open issue.
2. Comment on the issue if you want to work on it.
3. Fork the repository or create a branch if you have access.
4. Make focused changes.
5. Run local checks.
6. Open a pull request.

## Repositories

- Frontend: https://github.com/HavenOnStellar/Haven_Frontend
- Contracts: https://github.com/HavenOnStellar/Haven_Contracts
- Docs: https://github.com/HavenOnStellar/Haven_Docs

## Branch naming

Use descriptive branch names:

```text
feature/vendor-verification-page
fix/bounty-validation
docs/contract-events
```

## Commit style

Use conventional commits where possible:

```text
feat(frontend): add vendor verification page
fix(contracts): reject invalid bounty amounts
docs: document contract events
```

## Pull requests

A good PR should include:

- clear title
- summary of changes
- related issue link
- screenshots for UI work
- tests or explanation of testing

## Code of conduct

Be respectful, constructive, and inclusive. Haven is intended to protect people and communities, and the project community should reflect that mission.
