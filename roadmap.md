# Roadmap

Haven is being developed in phases.

## Phase 1: Core Registry

- Soroban contract architecture
- Device state storage
- Registration flow
- Stolen-device reporting
- Recovery flow
- Insurance claim flow
- Frontend landing page
- GitHub Actions CI
- Open-source issue backlog

## Phase 2: Contract Completeness

- SAC token transfers for bounty escrow
- Bounty payout to finder
- Contract events for indexers
- Minimum bounty validation
- Stronger insurance claim rules
- Optional device lookup behavior

## Phase 3: Frontend Product Flows

- Vendor verification page
- User dashboard
- Device registration form
- Stolen report form
- Recovery confirmation form
- Wallet connection status

## Phase 4: Wallet and Onboarding

- Freighter wallet integration
- Passkey Kit exploration
- Launchtube fee abstraction
- Safer IMEI hashing flow

## Phase 5: Fiat Rails and Insurance Layer

- SEP-10 authentication
- SEP-24 deposit flow
- USDC bounty funding
- Insurance provider dashboard
- Proof-of-loss API

## Phase 6: Scale

- Multi-anchor support
- Fleet registration
- Mobile app exploration
- Privacy-preserving recovery and ownership proofs
